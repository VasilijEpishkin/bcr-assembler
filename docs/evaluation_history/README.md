# История оценок сборщиков

Сводные таблицы всех полных прогонов и пилотов и отчёт по актуальным веткам. Таблицы и отчёт пересобирает скрипт `scripts/collect_evaluations.py` из каталогов `benchmark_*` веток симуляции.

## Файлы

| файл | что внутри |
|---|---|
| `full_runs_summary.tsv` | recall и CDR3 каждого полного бенчмарка: прогон, датасет, ветка, схема оценки + исходные колонки (`tool`, `group_by`, `group`, `templates`, `exact_full_frac`, `one_diff_full_frac`, `near_full_frac`, `partial_frac`, `missing_frac`, `cdr3_in_contig_frac`) |
| `full_runs_precision.tsv` | precision контигов по образцам; в новой схеме — ещё доли классов структуры |
| `full_runs_structure.tsv` | структура контигов по поддержке ридами (`table=structure_by_support`) и пороги отсечения по поддержке (`table=support_thresholds`) |
| `full_runs_comparison.tsv` | сравнение запусков: строка = датасет × ветка × сборщик, колонки — `exact_full_frac` и `cdr3_in_contig_frac` по схемам оценки |
| `pilots.tsv` | пилоты в длинном формате: `pilot`, `condition`, `metric`, `value`, `source` |
| `assembler_comparison_report.md` | отчёт по актуальным веткам (200 нг и текущая): результаты TRUST4, MiXCR, rnaSPAdes, metaSPAdes, rnaviralSPAdes, Trinity, GATHeR, расчёт каждой метрики, стадии сборщиков |
| `fixed_pcr_fold_report.md` | отдельный отчёт по сценарию фиксированных кратностей ПЦР (ветка `rpc1`): параметры, глубина, результаты всех сборщиков для человека и мыши; метрики определены в `assembler_comparison_report.md` |

## Полные прогоны

В таблицах только два последних сценария; предыдущие сценарии (база `in5ng_ss250`, `ssnone`, `ss300`, 200 нг без отбора) есть в истории git.

| прогон (`run`) | ветка симуляции | что отличалось |
|---|---|---|
| `200ng` | `… in200ng_rb3x_ss200-350h25_pcr1c30_pcr2c5_seq1e-3_al1e-1` | порция 200 нг продукта ПЦР1 (1/10 продукта), ПЦР1 30 циклов, ПЦР2 5 циклов, на секвенирование 1/1000; в имени ветки отбор 200–350 нт, но в provenance записан гауссов отбор 250 ± 40 нт (см. конец отчёта) |
| `current` | `… rb3x_ss200-350h25_pcr1c30_pcr2c5_seq1e-3_al1e-1` | порция 1/10 пула ПЦР1, те же циклы и доля на секвенирование; отбор по длине: вероятность 1 для 200–350 нт, вне диапазона 2^(−d/25) |

Оба прогона посчитаны всеми семью сборщиками (TRUST4, MiXCR, rnaSPAdes, metaSPAdes, rnaviralSPAdes, Trinity, GATHeR) для мыши и человека.

## Схемы оценки

| схема | смысл |
|---|---|
| `templates_whole_vj` | каждый шаблон эталона отдельно, вся V…J. У мыши завышает потери: первые ~20 нт V…J задаёт FR1-праймер, и одна молекула числилась несколькими шаблонами |
| `unique_vj_trim20` (мышь) / `unique_vj_trim0` (человек) | уникальные V…J без первых 20 нт (мышь, зона FR1-праймера) или целиком (человек, праймер в лидере). `exact_full` — эталонная V…J входит в контиг подстрокой (на любой цепи); `one_diff_full` — одно отличие с учётом оснований, обрезанных выравниванием на концах; структура контигов (`exact_verified`, `exact_unverified`, `exact_fragment`, `mosaic`, `unverified_variant`, `novel_error`, `chimera`, `other`, `unmapped`); поддержка ридами, пороги поддержки по любому точному контигу; CDR3 — junction в любом контиге образца, клонотипы по образцам |
| `unique_vj_trim45_15` | то же, но у эталонной V…J убраны первые 45 и последние 15 нт: exact full[45:-15], см. разделы 1 и 2 `assembler_comparison_report.md` |

## Пилоты (`pilots.tsv`)

| `pilot` | условия |
|---|---|
| `trust4_params_ERR346600` | TRUST4 по умолчанию (2 и 16 потоков) против `--repseq`; выбран режим по умолчанию |
| `rnaspades_modes` | rnaSPAdes по умолчанию, `-k 55,77,99`, `spades.py --isolate` на полном образце человека и на 150 IGL-шаблонах высокой глубины |
| `vdjer_benchmark`, `vdjer_runs`, `vdjer_autopilot` | все запуски V'DJer (окна, фильтр покрытия, `e0/e1`, `-jext`), оценки и решения автопилота; V'DJer закрыт (0 контигов при фильтре покрытия) |
| `collapse_rule_on_human_umi` | правило схлопывания мыши (порог родителя 3/5/10×) против истины по UMI человека |
| `igrec_vs_rule_trim30` | IgReC против правила 3× и 10× одним оценщиком (внутренняя часть V…J) |
| `trust4_inexact_whole_vj` | разбор неточных сборок TRUST4 по всей V…J (с праймерной зоной) |
| `spades_modes_ERR346600` | metaSPAdes и rnaviralSPAdes против TRUST4 и rnaSPAdes (мышь ERR346600, база) |
| `benchmark_audit`, `benchmark_audit_tables` | независимая проверка бенчмарка другими методами (поиск подстроки, редакционное расстояние, пересчёт сводных таблиц) |
