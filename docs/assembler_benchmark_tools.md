# Инструменты для benchmark сборки AIRR/BCR/TCR reads

## Рекомендация

Основная панель для первого воспроизводимого прогона: **TRUST4 + rnaSPAdes + IgReC**. **MiXCR** технически важен, но его текущая Academic License запрещает раскрывать performance information и benchmarks без отдельного разрешения; до письменного согласования MiXCR можно использовать только для внутренней оценки. `pRESTO AssemblePairs` следует оставить как baseline перекрывающегося PE merge, а не считать полноценным de novo repertoire assembler.

**Практический дизайн benchmark:** основной набор должен разделять (1) AIRR-aware reconstruction — TRUST4 и MiXCR, (2) reference-free transcript assembly — rnaSPAdes, опционально Trinity, (3) amplicon/UMI read consensus — pRESTO и legacy IgReC, (4) CDR3-only TCR comparator — CATT. Для каждого инструмента отдельно считать exact nucleotide recovery полного truth-contig, exact/near-exact CDR3, V/J correctness, chimera/split/merge rate и abundance error; partial или imputed calls не смешивать с exact assemblies. Версии и активность проверены по официальным release/repository pages на 2026-09-22; никакие файлы или репозитории не изменялись.

## Метрики truth-based benchmark

- Разделить benchmark на два трека: (1) обогащённая AIRR/Ig-Seq библиотека и (2) обычный RNA-seq с AIRR-транскриптами на фоне транскриптома. Иначе сравнение специализированных сборщиков с rnaSPAdes будет методологически нечестным.
- Сформировать независимые панели human и mouse с PE150, реалистичным распределением insert-size и ошибок; варьировать глубину, клональность, близкородственные клоны и уровень SHM. Нужны не менее трёх случайных реплик каждого сценария.
- Оценивать каждый локус отдельно и давать macro-average. Основной диагностический набор — равное представительство локусов; отдельный несбалансированный набор допустим только как явно обозначенная модель реалистичной смеси.
- Contig/clonotype recovery: recall, precision и F1 относительно truth, отдельно для полного V(D)J, CDR3-содержащих и частичных реконструкций; дополнительно стратифицировать по abundance и покрытию.
- Exact sequence: однозначное one-to-one соответствие полной целевой последовательности без замен и indel. Near-exact: заранее зафиксированный порог, например ≥99% identity при ≥95% покрытия truth; показать также распределение edit distance и чувствительность к порогу.
- V/J/CDR3 correctness: accuracy V и J отдельно на уровнях allele, gene и family; exact CDR3 nucleotide, exact CDR3 amino-acid, правильность границ и productive-status. Использовать единое определение AIRR/IMGT junction: https://docs.airr-community.org/en/stable/datarep/rearrangements.html
- Для generic assembler выполнять одинаковую пост-аннотацию всех contigs одним AIRR-аннотатором и фиксированной germline-базой. Нативные V/J/CDR3-вызовы специализированных инструментов оценивать вторым, отдельным слоем.
- Abundance distortion: сравнивать истинное число фрагментов/молекул с восстановленным abundance, включая пропущенные клоны; сообщать Spearman, ошибку log2-fold, RMSE и Jensen–Shannon divergence, отдельно по локусам и abundance-bin.
- Chimeras: считать contig химерным, если неперекрывающиеся участки лучше соответствуют разным truth-молекулам; отдельно intra-locus, cross-locus и соединения разных клонов. Сообщать долю химер среди contigs и среди восстановленных нуклеотидов.
- Locus assignment: confusion matrix и macro-F1 для IGH/IGK/IGL/TRA/TRB/TRG/TRD; ambiguous и unsupported должны быть отдельными категориями, а не ошибочно принудительно назначаться локусу.
- Runtime/RAM: wall-clock, CPU-time и peak RSS на одинаковом узле, фиксированном числе потоков и локальном диске; фиксировать версии, контейнеры, параметры и включать время обязательного mapping/post-annotation.
- Не разрешать скрытое дополнение последовательности germline-нуклеотидами: отключать imputation/extension, где возможно, либо маркировать такие основания и оценивать observed-only и imputed результаты раздельно.

## Предлагаемый порядок внедрения

1. TRUST4 — основной AIRR-aware assembler для human/mouse PE150.
2. rnaSPAdes — reference-free transcriptome baseline; contigs затем аннотируются единым IgBLAST.
3. IgReC — BCR-focused comparator для repertoire/amplicon данных.
4. pRESTO — baseline текущего overlap merge.
5. MiXCR — только после проверки условий публикации benchmark.
6. ImReP/CATT — отдельный CDR3-centric трек; CATT для текущей mouse IGH задачи не подходит.
7. Trinity — опциональный второй generic transcriptome baseline, если хватает ресурсов.
