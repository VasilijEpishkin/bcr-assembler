# Паспорт датасетов: что известно о подготовке библиотек

Источник каждой строки — методы статьи датасета. «Не указано» значит, что в статье числа нет и его надо спрашивать
у авторов или лаборатории. Праймеры и адаптеры человека — в разделе «Праймеры и адаптеры (PRJEB30386)».

## Мышь — ERP003950 (BioProject PRJEB4643, ArrayExpress E-MTAB-1896)

Статья: Greiff V. et al., BMC Immunology 2014, DOI 10.1186/s12865-014-0040-5 (PMC4233042).

| параметр | значение |
|---|---|
| материал | плазмобласты и плазматические клетки (CD138+) селезёнки и костного мозга мышей BALB/c, иммунизация NP-CGG, день 14 |
| число клеток | ≈ 3·10⁶ (сценарий 1M, одна мышь) и ≈ 2,5·10⁷ (9M, девять мышей); точные числа по образцам не указаны |
| РНК | PureLink RNA Mini Kit; выход РНК не указан |
| обратная транскрипция | Maxima RT, праймер oligo(dT), 500 нг РНК на реакцию; число реакций и условия не указаны |
| праймеры ПЦР | форвард: смесь из 19 частично вырожденных праймеров на FR1; реверс: один IgG-специфичный на CH1, `CARKGGATRRRCHGATGGGG` |
| адаптеры | добавлены в той же ПЦР (адаптер TruSeq на 5′-конце форвард-праймеров, индекс на реверсе); второй индексирующей ПЦР нет |
| ПЦР | 50 мкл: 0,2 мкМ праймеров, 200 мкМ dNTP, 2 мкл нечищеной кДНК, 0,25 мкл Taq (NEB, не высокоточная); 10 реакций параллельно на образец |
| циклы | 28 = 4 цикла (отжиг 50 °C) + 4 (55 °C) + 20 (63 °C) |
| очистка | гель 1%, полоса ~550 нт (в другом месте статьи 570 нт) |
| выход библиотеки | ≈ 450 пг (1M) и ≈ 1200 пг (9M) по Bioanalyzer; метод количественной оценки не указан |
| секвенирование | MiSeq, 2×250 нт; ≈ 3,2·10⁶ ридов на реплику, средний Phred 33–36 |
| фрагментация и отбор по длине | нет: секвенируется целый ампликон |

Связь с симуляцией: шаблон симуляции (V-праймер…C-праймер, без адаптеров) имеет медиану 394 нт; с адаптерами TruSeq
на обоих концах это ≈ 550 нт, как в статье.

## Человек — PRJEB30386

Статья: Vázquez Bernat N. et al., Frontiers in Immunology 2019, DOI 10.3389/fimmu.2019.00660 (PMC6459949).
Karolinska Institutet. Библиотеки IgM, IgG, IgK, IgL; методы 5′RACE и 5′MTPX (мультиплекс на лидер).
Ниже параметры 5′MTPX, как в нашей симуляции (форвард-праймеры на лидере).

| параметр | значение |
|---|---|
| материал | PBMC, заморожены по 10·10⁶ клеток/мл; число клеток на экстракцию не указано |
| РНК | по умолчанию 200 нг (проверены 50, 100, 200, 500 нг; при 200 и 500 нг больше уникальных HCDR3 на V-аллель) |
| обратная транскрипция | набор Sensiscript, 37 °C, 1 ч; цепь-специфичные реверс-праймеры с хвостом Read2 и UMI |
| UMI | 21 нт (5′MTPX); у 5′RACE 25 нт |
| праймеры | форвард: в лидерных последовательностях V-генов; реверс: IgM, IgG1–4 (один праймер), IgL (один консервативный) |
| очистка кДНК | GeneJET PCR purification kit; вход ПЦР 2–4 мкл очищенной кДНК |
| ПЦР | KAPA HiFi HotStart ReadyMix (высокоточная); 25 циклов для библиотек из 200 нг РНК (в методах число циклов не указано, оно названо в результатах) |
| индексирующая ПЦР | 10 циклов, шаблон 5–10 нг очищенного геля продукта |
| очистка ампликона | гель (Qiagen Gel Purification Kit); бусин нет |
| длина ампликона | ≈ 480 нт, средняя длина последовательности < 500 нт |
| выход | числа не приведены |
| секвенирование | MiSeq v3, 2×300 нт, PhiX 13% (12 пМ) |
| фрагментация и отбор по длине | нет |
| ошибки, химеры | ошибки ПЦР и прибора не разделены; химеры «не считаются серьёзной проблемой» |

Связь с симуляцией: «5 нг на фрагментацию» и «10 циклов ПЦР2» в нашей модели соответствуют 5–10 нг и 10 циклам
индексирующей ПЦР этого протокола.

### Праймеры и адаптеры (PRJEB30386)

Источники: статья (DOI 10.3389/fimmu.2019.00660, PMC6459949); проект ENA [`PRJEB30386`](https://www.ebi.ac.uk/ena/browser/view/PRJEB30386),
библиотеки `A007_IgM`, `A007_IgG`, `A007_IgK`, `A007_IgL`; [дополнительная таблица 2](https://pmc.ncbi.nlm.nih.gov/articles/instance/6459949/bin/Table_2.pdf)
(праймеры 5′MTPX на лидер V и на константную область), [дополнительная таблица 3](https://pmc.ncbi.nlm.nih.gov/articles/instance/6459949/bin/Table_3.pdf)
(олиго P5/P7 и индексы), [протокол](https://pmc.ncbi.nlm.nih.gov/articles/instance/6459949/bin/Presentation_1.pdf) (индексирующая ПЦР
праймерами `P5_R1` и `P7_R2` с индексом).

Ориентация ридов в FASTQ (протокол 5′MTPX):

- **R1 начинается с последовательности праймера на лидер V.** В таблице 2 — 25 праймеров `Hu_VH_MTPX`, 21 `Hu_VK_MTPX` и
  33 `Hu_VL_MTPX`; их общий хвост праймера секвенирования Read1 стоит перед вставкой и в начале R1 не читается.
- **R2 начинается с вырожденной UMI, за ней — праймер на константную область цепи.** В таблице 2 перед константной частью
  20 вырожденных нуклеотидов; в настройках IgDiscover статьи UMI названа 21-нуклеотидной, а в FASTQ постоянный мотив
  праймера стоит после 20 переменных оснований.
- **Адаптеры индексирующей ПЦР** (таблица 3): `P5_R1` со стороны R1, один из `P7_R2_I*` со стороны R2. Эти внешние части
  лежат вне вставки и попадают в FASTQ, только если вставка короче рида.

Адаптеры на 3′-конце рида при прочтении насквозь — обратные комплементы хвостов праймеров секвенирования из таблицы 3:

| рид | адаптер на 3′-конце | откуда |
|---|---|---|
| R1 | `AGATCGGAAGAGCACACGTCTGAACTCCAGTCAC` | обратный комплемент общего хвоста Read2 `GTGACTGGAGTTCAGACGTGTGCTCTTCCGATCT` в `P7_R2_I*` |
| R2 | `AGATCGGAAGAGCGTCGTGTAGGGAAAGAGTGTAG` | обратный комплемент хвоста Read1 `CTACACTCTTTCCCTACACGACGCTCTTCCGATCT` в `P5_R1` |

Праймеры на 3′-конце по цепям:

| прогон | библиотека | праймер из таблицы 2 |
|---|---|---|
| `ERR3004229` | IgM | семейство `Hu_IgM_MTPX`; в таблице есть экспериментальные варианты `-50/-100/-150`, граница праймера сверяется с FASTQ |
| `ERR3004230` | IgG | `Hu_IgG_MTPX` |
| `ERR3004231` | IgK | `Hu_IgK_MTPX` |
| `ERR3004232` | IgL | `Hu_IgL_MTPX` |

## Сравнение

| | мышь ERP003950 | человек PRJEB30386 |
|---|---|---|
| форвард-праймеры | FR1, смесь из 19 вырожденных | лидер |
| полимераза | Taq, не высокоточная | KAPA HiFi |
| циклов ПЦР1 | 28 | 25 |
| индексирующая ПЦР | нет | 10 циклов |
| UMI | нет | 21 нт |
| прибор | MiSeq 2×250 | MiSeq 2×300 |
| длина шаблона в симуляции | медиана 394 нт | медиана 461 нт |
| стартовые молекулы N0 в симуляции | 4 084 465 на шесть образцов: сумма множественности (риды после схлопывания) | 3 061 773: число UMI, измерено |

Оба датасета секвенировали целый ампликон без фрагментации. Фрагментация, отбор по длине и NovaSeq PE150 в нашей
симуляции моделируют будущий протокол лаборатории, а не протокол датасета.
