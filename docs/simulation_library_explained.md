# Симуляция библиотеки: термины, параметры, формулы и код

Разбор ноутбуков `simulate_{mouse,human}_post_annotation_filtered_insilicoseq_150bp_novaseq.ipynb`: от пула ПЦР1 до списка ридов по фрагментам. В файле собраны термины симуляции, параметры, формулы и код по стадиям. Термины сборки и метрики — в `glossary.md`, сценарии и результаты — в `simulation_scenarios.md`.

## 1. Вся цепочка одной схемой

```
шаблоны (ампликоны) ── у каждого свои исходные копии
        │ ПЦР1: 30 циклов, у каждого шаблона своя эффективность, общий потолок K
        ▼
ПУЛ ПЦР1: шаблон → N копий                         (≈ 4,7·10¹² молекул у мыши)
        │ порция: случайные 1/10 пула, 200 нг        ← отбор 1 (multinomial)
        ▼
ПОРЦИЯ: шаблон → m копий                           (≈ 4,7·10¹¹ молекул)
        │ каждая молекула рвётся по одной случайной связи → два куска
        │ кусок проходит отбор по длине с вероятностью p(L)
        ▼
ПУЛ КУСКОВ: у шаблона виды (start, end), у вида k копий    ← отбор 2 (Poisson)
        │ ПЦР2: 5 циклов, у каждого вида куска своя эффективность
        ▼
КОПИИ ПОСЛЕ ПЦР2: вид → cp копий
        │ на секвенатор идёт 1/1000 продукта                ← отбор 3 (binomial)
        ▼
        │ риды раздаются по видам куска пропорционально копиям  ← отбор 4 (multinomial)
        ▼
файлы: read_counts, selected_fragments.fasta, allocation.tsv → InSilicoSeq → FASTQ PE150
```

В цепочке четыре случайных отбора. Каждый можно найти в коде по названию распределения (раздел 8).

## 2. Термины и дерево понятий

### Дерево понятий

Каждая строка включает в себя строки под ней; справа — где в симуляции это число появляется.

```
ДАТАСЕТ (мышь ERP003950 / человек PRJEB30386)
└─ ОБРАЗЕЦ                      мышь — 6 прогонов ERR346596…601, человек — один объединённый
   └─ ШАБЛОН (ампликон ПЦР1)    последовательность V-праймер…V…J…C-праймер из прочтений датасета
      │                         после аннотации и фильтров; из него получаются все риды
      ├─ ЭТАЛОН                 участок V…J шаблона; по нему оценивается сборка
      │                         (одинаковые V…J разных шаблонов — один эталон)
      └─ МОЛЕКУЛЫ (копии)       стартовых — риды после схлопывания (мышь) / число UMI (человек);
         │                      после ПЦР1 — N копий, пул ПЦР1 = копии всех шаблонов вместе
         └─ ПОРЦИЯ              случайная 1/10 пула, 200 нг: у шаблона m копий (aliquot[i])
            └─ КУСКИ            каждая молекула рвётся по одной связи → 2 куска
               └─ ВИД КУСКА     пара (start, end); у вида k копий — после отбора по длине
                  │             p(L), от размера куска зависит, попадёт ли он в ПЦР2
                  └─ КОПИИ ВИДА после ПЦР2: cp копий; на секвенатор идёт 1/1000 (thinned)
                     └─ ПАРА    R1 + R2, каждая 150 нт; пар у вида — pairs, всего — бюджет ридов
                        └─ РИД  один из двух концов пары
```

Остальное связывает ветка:

```
ВЕТКА = один набор параметров (имя кодирует их, §3)
 └─ для каждого образца: ПЦР1 → порция → куски → ПЦР2 → риды
```

Термины сборки (контиг, клонотип, гаплотип, фаза) и метрики — в `glossary.md`. С симуляцией связана только эталонная часть: эталон и «проверенный» (подтверждён в исходных данных).

### Термины

| термин | простыми словами |
|---|---|
| **шаблон** | один ампликон: V-праймер…V…J…C-праймер; из него получаются все риды (`00_primary_truth/<образец>_templates.fasta`) |
| **молекула / копия** | физическая копия шаблона. Стартовая — исходная одна; после ПЦР1 копий шаблона `N`; в порции `m` |
| **эталон** | участок V…J шаблона; одинаковые V…J объединены; у мыши сравнение идёт без первых 20 нт (там праймер FR1) |
| **пул ПЦР1** | все копии всех шаблонов после ПЦР1 (≈ 4,7·10¹² молекул у мыши) |
| **порция** | часть пула, которая идёт на фрагментацию: случайная выборка молекул из перемешанного пула; по массе 200 нг, по доле 1/10 пула |
| **кусок / фрагмент** | часть молекулы после разрыва; из одной молекулы получается два куска |
| **вид куска** | пара `(start, end)` — какой участок шаблона; у шаблона длины L их порядка 2·(L−1) |
| **отбор по длине `p(L)`** | вероятность, что кусок длины L попадёт в ПЦР2 (§6.2) |
| **λ (`lam`)** | ожидаемое число кусков данного вида на одну молекулу после отбора по длине (≈ p(L)/(L−1)) |
| **`cdf`** | накопленные суммы λ по видам кусков (`np.cumsum(lam)`); последний элемент — Σλ, ожидаемое число отобранных кусков на молекулу, около 1 |
| **рид, пара, мейт** | прочитанные концы фрагмента: R1 и R2 (мейты) составляют пару (`06_fastq_pe150/<образец>_R1/R2.fastq.gz`) |
| **вставка (insert)** | длина фрагмента между концами пары; оценивается по перекрытию R1/R2 |
| **бюджет ридов, глубина** | сколько пар ридов получит образец; в симуляции это и есть глубина секвенирования (§5) |
| **UMI** | случайная метка молекулы (только у человека); риды одной UMI дают консенсус — эталон |
| **образец** | один прогон секвенирования (мышь: ERR346596…601; человек: один объединённый) |
| **ветка** | один вариант симуляции с набором параметров; `results/<датасет>/simulated/<ветка>/` |
| **`rb3x`** | read budget: глубина = число сырых пар × 3 |
| **`1e-3`** | 0,001, то есть 1/1000 (0,1%) |

### Какое распределение что делает

```
банка с цветными шариками:  цвет = шаблон, число шариков цвета = число его копий

multinomial(n, доли)      вытащили n шариков → сколько каждого цвета в горсти;
                          частые цвета попадают чаще, редкие могут не попасть
                          (шарики «возвращаются»: шансы не меняются; при горсти 1/10 банки
                          разница с настоящей выборкой без возврата мала)
binomial(копии, p)        у каждой из копий независимый шанс p остаться → сколько осталось
Poisson(m·λ)              число успешных событий, когда попыток m много, а шанс каждой λ мал:
                          среднее m·λ (так считается число копий вида куска в порции)
Beta(a, b)                эффективность ПЦР шаблона: случайное число в [0, 1] около среднего 0,85
```

Правило выбора: **что зафиксировано, то и определяет распределение**.

| если зафиксировано | распределение | где |
|---|---|---|
| общее число (молекул порции, ридов) | multinomial: n единиц делятся между шаблонами или видами, сумма жёсткая | отборы 1 и 4 |
| доля, а число не задано | binomial: у каждой копии независимый шанс, итог колеблется | отбор 3 |
| ничего, события редкие и независимые | Poisson: число молекул, давших данный вид куска | отбор 2 |

Порция и копии на секвенатор — случайные выборки из перемешанной пробирки: молекулы разных шаблонов смешаны, и у каждой одинаковый шанс попасть в порцию, а не «первая десятая часть» в каком-то порядке.

## 4. ПЦР1: пул молекул

### 4.1. Эффективность шаблона

У каждого шаблона своя эффективность цикла `eff`, случайная из Beta со средним 0,85:

```python
alpha = mean * concentration          # 0,85 · 80 = 68
beta  = (1 - mean) * concentration    # 0,15 · 80 = 12
eff   = rng.beta(alpha, beta, size=len(rows))
```

Концентрация 80: чем больше, тем меньше разброс эффективности между шаблонами. Из-за разброса одни шаблоны «выигрывают» (джекпот), другие отстают.

### 4.2. Рост с общим потолком (финальная ветка)

Когда задана доля порции (`BCR_PCR1_ALIQUOT_FRACTION`) или потолок `BCR_PCR1_SATURATION_K`, весь пул растёт одновременно, и рост замедляется по мере заполнения реакции:

```python
def branching_pcr_saturated(n0, efficiency, cycles, capacity, rng):
    n = n0.copy()
    for _ in range(cycles):
        free = max(0.0, 1.0 - n.sum() / capacity)   # доля свободной ёмкости
        n += rng.binomial(n, efficiency * free)     # каждая копия делится с шансом eff·free
    return n
```

Потолок вычисляется из массы порции:

```
K = (200 нг → число молекул порции) ÷ 0,1
```

Поэтому пул после ПЦР1 примерно в 10 раз больше порции, и порция составляет 1/10 пула (в сводке `library_aliquot_fraction_of_pcr1 = 0,1001`: средняя длина для числа молекул берётся уже после ПЦР1).

### 4.3. Рост без потолка и `PCR_MAX_COPIES`

```python
def branching_pcr(n0, efficiency, cycles, rng):
    n = int(n0)
    for _ in range(cycles):
        n += rng.binomial(n, efficiency)
        if n >= PCR_MAX_COPIES:          # 10¹²: предел числа копий одного шаблона
            return PCR_MAX_COPIES
    return n
```

`PCR_MAX_COPIES` используется только в этом режиме (без потолка K и без доли порции). В финальной ветке, где задана доля порции, он не действует: рост ограничивает потолок K из п. 4.2.

## 5. Глубина секвенирования (бюджет ридов)

### 5.1. Общее число пар образца

Бюджет ридов — это глубина секвенирования: число пар, которое получит образец (сырые пары × `rb`). Доля 1/1000 из ПЦР2 число ридов не меняет: она определяет, какие виды кусков ещё есть в пробе и с какими весами делятся риды.

```python
def get_read_budget(sample):
    # match_raw_pairs: число сырых пар образца × READ_BUDGET_MULTIPLIER
    return int(round(count_fastq(R1) * 3))
```

Режим `fixed` берёт число `FIXED_READ_PAIRS`.

### 5.2. Распределение по локусам (человек)

Человеческий образец — четыре библиотеки (IgM, IgG, IgK, IgL), слитые в один FASTQ. Исходные библиотеки секвенировали каждую со своей глубиной, поэтому глубину локусов задаём по сырым данным, а не по числу копий после ПЦР (иначе доля локуса определялась бы случайными джекпотами):

| локус | сырых пар | доля |
|---|---|---|
| IGH (IgM + IgG) | 2 509 309 | 55,1% |
| IGK | 958 261 | 21,0% |
| IGL | 1 085 144 | 23,8% |

```python
exact  = {l: target * n / sum(depth.values()) for l, n in depth.items()}
budget = {l: int(np.floor(v)) for l, v in exact.items()}
# остаток от округления раздаётся локусам с наибольшей дробной частью — сумма сходится точно
for l in sorted(exact, key=lambda x: exact[x] - budget[x], reverse=True)[: target - sum(budget.values())]:
    budget[l] += 1
```

У мыши локус один (IGH), блок ничего не меняет. Образцов мыши шесть, они считаются раздельно (ERR346596–601), у человека один смешанный образец.

## 6. Фрагментация и отбор по длине

### 6.1. Один разрыв на молекулу

Молекула длины `L` рвётся по одной из `L−1` связей с равной вероятностью. Разрыв по связи `c` даёт два куска `[0, c)` и `[c, L)`:

```
молекула L = 10:   ━━━━━━━━━━
связи:               1 2 3 4 5 6 7 8 9         (L−1 = 9 равновероятных)
разрыв по связи 3:   ━━━ | ━━━━━━━             куски [0,3) и [3,10)
```

На молекулу получается ровно 2 куска, их суммарная длина равна `L` (проверяется в коде).

### 6.2. Отбор по длине

Для куска длины `L`:

```
d(L) = 200 − L    если L < 200
d(L) = 0          если 200 ≤ L ≤ 350
d(L) = L − 350    если L > 350

p(L) = 2^(−d(L)/h),   h = 25 нт
```

Кусок короче 152 нт не берётся вообще (InSilicoSeq не читает PE150 с коротких фрагментов). Каждый кусок отбирается независимо:

| длина, нт | 152 | 175 или 375 | 190 или 360 | 200–350 | 400 | 430 | 500 |
|---|---|---|---|---|---|---|---|
| вероятность | 0,26 | 0,50 | 0,76 | 1 | 0,25 | 0,11 | 0,016 |

В коде вероятность применяется не кусок за куском, а к ожидаемому числу: `λ = E · p(L)`. Это эквивалентно независимому включению по `u < p(L)`, но считается быстро (разделы 7.4–7.5).

### 6.3. Модель кусков `retained_fragment_model(L)`

```python
s, e, E = expected_terminal_fragments(L)     # куски (start, end) и их ожидаемое число на молекулу
assert (E * (e - s)).sum() ≈ L               # разрыв не теряет нуклеотиды
lam  = E * _size_selection_probability(e - s)   # ожидаемое число после отбора по длине
keep = lam >= FRAGMENT_MODEL_MIN_EXPECTED    # 1e-12: пренебрежимо редкие виды выбрасываются
# возвращает: начала, концы, λ, 2 (кусков на молекулу), отброшенную долю, cumsum(λ)
```

Для каждой длины шаблона модель считается один раз и кэшируется.

## 7. `run_library_stage`: этап библиотеки по шагам

### 7.1. Чтение и зерно

```python
rows = read_dict_rows(inp)                    # пул ПЦР1: шаблоны и их копии
seqs = dict(iter_fasta(TRUTH_DIR / f"{sample}_templates.fasta"))

```

Зерно детерминировано: повторный запуск даёт тот же результат.

### 7.2. Порция — отбор 1

```python
lengths = np.array([r["length"] for r in rows])
pcr1    = np.array([r["pcr_copies"] for r in rows], dtype=float)
mean_len = (pcr1 * lengths).sum() / pcr1.sum()     # средняя длина молекулы пула
n_input  = int(LIBRARY_INPUT_NG * 1e-9 / (mean_len * 650) * AVOGADRO)   # молекул в 200 нг
aliquot  = rng.multinomial(n_input, pcr1 / pcr1.sum())   # случайная порция
```

Порция — случайная выборка из перемешанного пула, а не его первая десятая часть: молекулы всех шаблонов смешаны, у каждой одинаковый шанс попасть в порцию. Число молекул порции `n_input` задано массой (200 нг), поэтому распределение multinomial. Схема: вес шаблона = доля его копий в пуле; в порцию «вытягивается» `n_input` молекул, `aliquot[i]` — число копий шаблона `i` в порции (`m` в коде ниже). Копий у шаблона после ПЦР1 около 10⁷, в порции около 10⁶, поэтому шанс шаблону не попасть в порцию практически нулевой.

### 7.3. Сколько ридов получит каждый шаблон

```python
per_molecule = {L: retained_fragment_model(L)[2].sum() for L in уникальные длины}   # Σλ для длины L
weight = aliquot * per_molecule[length]       # ожидаемое число отобранных кусков шаблона
reads[idx] = rng.multinomial(n, weight[idx] / weight[idx].sum())   # n — бюджет локуса
```

Риды делятся между шаблонами пропорционально числу отобранных кусков: больше копий в порции и длиннее шаблон — больше ридов. Шаблон может получить ноль ридов, и это нормально (выпадение).

### 7.4. Пул кусков шаблона — отбор 2

Для шаблонов с ридами: сколько копий каждого вида куска `(start, end)` в порции. Копий шаблона в порции `m`, каждая даёт данный вид с малой вероятностью `λ` — число получаемых копий вида ≈ Poisson(m·λ):

```python
if m * cdf[-1] < len(lam):      # кусков в порции меньше, чем видов: большинство видов получит 0
    K      = rng.poisson(m * cdf[-1])                    # всего кусков выпало
    points = rng.random(K) * cdf[-1]                     # K случайных точек на «линейке» из отрезков λ
    picks  = np.searchsorted(cdf, points, side="right")  # в какой отрезок (вид) попала каждая точка
    nz, k  = np.unique(picks, return_counts=True)        # nz — виды, k — число копий каждого
else:
    k  = rng.poisson(m * lam)                            # прямое число копий каждого вида
    nz = np.flatnonzero(k); k = k[nz]
```

```
линейка Σλ:   |λ₁|λ₂ |λ₃|    λ₄    |...|
дротик →         ↑ попал в λ₂ → выпал вид 2
```

Разрыв один на молекулу, и Poisson ему не противоречит: у каждой из `m` молекул шанс дать данный вид куска равен `λ` (разрыв пришёлся на эту связь и кусок прошёл отбор), так что число копий вида — binomial(m, λ), а при малом `λ` и большом `m` оно совпадает с Poisson(m·λ). Оба варианта дают одно и то же распределение (свойство Пуассона), но первый не перебирает сотни видов, когда копий мало. У мыши в порции около 10⁶ копий шаблона, у человека около 2,5·10⁵, поэтому обычно работает вторая ветка.

Если у шаблона с 1–2 копиями в порции ни один кусок не прошёл отбор, а риды по бюджету положены, берётся один кусок по `λ` (счётчик `templates_single_fragment_fallback`; в финальных ветках он равен 0).

## 8. Где какой случайный отбор

| отбор | строка | что отбирается | зачем |
|---|---|---|---|
| 1 | `rng.multinomial(n_input, pcr1/…)` | молекулы порции из пула ПЦР1 | порция ПЦР1: 200 нг, 1/10 продукта |
| 2 | `rng.poisson(m·λ)` / `searchsorted` | виды кусков из порции | один разрыв на молекулу + отбор по длине |
| 3 | `rng.binomial(cp, 1e-3)` | копии после ПЦР2 | на секвенирование идёт 1/1000 |
| 4 | `rng.multinomial(n, cp/…)` | риды по видам куска | глубина секвенирования |

Кроме них случайны эффективность шаблона и вида куска (`Beta`) и рост самих ПЦР (`binomial` на каждом цикле).
