# PRJNA1226555 — мышь, лёгкие цепи IGK/IGL

Ноутбуки и отчёты QC датасета лёгких цепей мыши (образец SRR32426580, BALB/cByJ). Датасет нужен для построения
смешанного эталона IGH+IGK+IGL вместе с ERP003950.

## Порядок обработки

1. удаление адаптеров cutadapt и фильтрация пар fastp (`-q 30 -u 40 -l 250`) — `adapter_trim_light_mouse.ipynb`;
2. удаление праймеров — `primer_trim_light_mouse.ipynb`;
3. сборка пар ридов pRESTO — `presto_light_mouse.ipynb`.

## Выбор ветки предобработки

Сравнивались четыре ветки: cutadapt с обрезкой по качеству и fastp, минимальная длина 200 и 250 нт
(`compare_light_minlen_mouse.ipynb`, `compare_light_fastp_minlen_mouse.ipynb`, `compare_light_primer_strategy_mouse.ipynb`,
`select_mouse_heavy_light_branches.ipynb`; сводки — `comparisons/`). Критерий — число строгих продуктивных полных
последовательностей V…J без стоп-кодона:

| ветка | продуктивных полных | уникальных V…J |
|---|---|---|
| fastp, ≥250 нт | 306 309 | 55 273 |
| fastp, ≥200 нт | 306 312 | 55 274 |
| cutadapt с обрезкой по качеству, ≥200 нт | 288 041 | 49 736 |
| cutadapt с обрезкой по качеству, ≥250 нт | 200 988 | 30 232 |

Выбрана ветка fastp с порогом 250 нт: результат не отличается от порога 200 нт, а фильтрация совпадает с тяжёлой
цепью ERP003950. Её результаты лежат под каноническими путями датасета.

## Смешанный эталон IGH+IGK+IGL

Тяжёлая и лёгкие цепи выбираются независимо, каждая по своему сравнению веток; порог длины одной цепи на другую не
переносится. Смешанный эталон — контролируемый синтетический набор, а не восстановление нативного спаривания H–L:

- IGH берётся из шести библиотек ERP003950, IGK/IGL — из SRR32426580 (BALB/cByJ);
- тяжёлые и лёгкие перестройки — отдельные молекулы-шаблоны, оценка сборки идёт отдельно по IGH, IGK и IGL; метрики
  спаривания нет, в манифесте `native_heavy_light_pairing=false`;
- в эталон входят только продуктивные полные записи без стоп-кодона с корректными V и J, участок
  `v_sequence_start…j_sequence_end` из A/C/G/T; уникальность — точная нуклеотидная V(D)J внутри (образец, локус);
- лёгкие цепи аннотируются по OGRDB BALB/c/ByJ (IGKV, набор 29; IGLV, набор 77) с IGKJ/IGLJ OGRDB;
- ERP003950 — два пула (1M: ERR346596, ERR346597, ERR346600; 9M: ERR346598, ERR346599, ERR346601); для каждого пула
  один состав лёгких цепей, общий для трёх технических повторов; число стартовых копий лёгких цепей равно числу
  тяжёлых в образце;
- соотношение κ:λ — два сценария: эмпирическое (по исходным данным) и 95:5;
- глубина IGH сохраняется: лёгкие цепи добавляют риды, а не забирают их у IGH.
