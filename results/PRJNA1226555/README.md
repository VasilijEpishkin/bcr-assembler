# PRJNA1226555 — мышь, лёгкие цепи IGK/IGL

Ноутбуки и отчёты QC датасета лёгких цепей мыши (образец SRR32426580, BALB/cByJ). Датасет нужен для построения
смешанного эталона IGH+IGK+IGL вместе с ERP003950 и пока не входит в основную линию сборки.

## Порядок обработки

1. удаление адаптеров cutadapt и фильтрация пар fastp (`-q 30 -u 40 -l 250`), без обрезки концов по качеству — `adapter_trim_light_mouse.ipynb`;
2. удаление праймеров — `primer_trim_light_mouse.ipynb`;
3. сборка пар ридов pRESTO — `presto_light_mouse.ipynb`.

## Выбор ветки предобработки

Сравнивались четыре ветки: cutadapt с обрезкой по качеству и fastp, минимальная длина 200 и 250 нт
(`compare_light_minlen_mouse.ipynb`, `compare_light_fastp_minlen_mouse.ipynb`, `compare_light_primer_strategy_mouse.ipynb`,
`select_mouse_heavy_light_branches.ipynb`; сводки — `comparisons/`). Критерий — число строгих продуктивных полных
последовательностей V…J без стоп-кодона:

| ветка | продуктивных полных | уникальных V…J |
|---|---|---|
| fastp, ≥250 нт | 306 309 | 55 273 |
| fastp, ≥200 нт | 306 312 | 55 274 |
| cutadapt с обрезкой по качеству, ≥200 нт | 288 041 | 49 736 |
| cutadapt с обрезкой по качеству, ≥250 нт | 200 988 | 30 232 |

Выбрана ветка fastp с порогом 250 нт: результат не отличается от порога 200 нт, а фильтрация совпадает с тяжёлой
цепью ERP003950. В репозитории опубликована только она, под каноническими путями; локальная рабочая копия хранит
все четыре ветки в `branches/` (`legacy_qtrim_min250`, `legacy_qtrim_min200`, `fastp_q30_u40_min250`, `fastp_q30_u40_min200`).

## Содержимое

- `notebooks/` — исполняемые ноутбуки;
- `<стадия>/fastqc/`, `<стадия>/multiqc/` — отчёты FastQC и MultiQC (`trimmed`, `pr_trimmed`, `merged`);
- `trimmed/fastp_reports/`, `<стадия>/*_summary.json` — сводки стадий;
- `comparisons/` — сводки сравнения веток.

FASTQ и AIRR-таблицы лежат на томе данных и в git не хранятся.
